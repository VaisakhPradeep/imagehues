# Daily Image Curation

This directory contains infrastructure for daily image curation workflow.

## Files

### `curation-picks.json`
Locked curation decisions using atomic color/mood tags. Each pick includes:
- `tags`: Ordered array of atomic tags; first tag = primary for titles (e.g., `["Sunset", "Gold", "Amber"]`)
- `tier`: Publishing tier (`"public"`, `"public-alt"`, or `"tag"`)
- `lockedAt`: ISO-8601 timestamp
- `lockedBy`: Curator name (e.g., `"vaisakh"`)

**Schema v2 (current):**
- Atomic multi-tags: hue/value tags + mood tags (NOT scene names)
- Tags are orderable; primary tag used for titles on `/palette/{id}/`
- Three tiers: `public` (indexed pages), `public-alt` (next candidates), `tag` (tags only)
- Two axes: `tagList.hue` (color/neutrals) + `tagList.mood` (atmosphere/style)

**Example entry:**
```json
{
  "picks": {
    "3": {
      "tags": ["Sunset"],
      "tier": "public",
      "lockedAt": "2026-09-28T08:27:00Z",
      "lockedBy": "vaisakh"
    },
    "4": {
      "tags": ["Teal", "Clay", "Dark", "Moody"],
      "tier": "tag",
      "lockedAt": "2026-09-28T08:27:00Z",
      "lockedBy": "vaisakh"
    },
    "10": {
      "tags": ["Sunset", "Gold", "Amber"],
      "tier": "public-alt",
      "lockedAt": "2026-09-28T08:27:00Z",
      "lockedBy": "vaisakh"
    }
  }
}
```

**Note:** Tags can mix hue (Teal, Clay) and mood (Dark, Moody) — order determines primary.

**Retired:** Schema v1 used scene categories (`keep`, `stretch`, `publicV1`). These are replaced by atomic color/mood tags.

### `palette-suggestions.json`
Vision-based scene category suggestions imported from PR 15 (cursor/palette-seo-urls-6fcb).
Maps image ID to suggested categories. NOTE: These are legacy scene suggestions, not the atomic tags used for final picks.

**Format:**
```json
{
  "5": ["Autumn", "Fog"],
  "13": ["Aurora", "Mountain"]
}
```

### Tag System (Schema v2)
Two separate tag axes defined in `curation-picks.json` → `tagList`:

#### Hue/Value Tags (25)
Color and neutral descriptors:
**Sunset, Autumn, Gold, Amber, Desert, Forest, Ocean, Teal, Clay, Cool grey, Mint, Ink, Purple, Magenta, Pink, Red, Coral, Cream, Olive, Sand, Navy, Burgundy, Rust, Emerald, Brown**

#### Mood Tags (14)
Atmosphere and style descriptors:
**Bold, Soft, Moody, Minimal, Warm, Cool, Dark, Bright, High-contrast, Muted, Vibrant, Calm, Dramatic, Earthy**

#### Tagging Guidelines
- **Mix axes:** Combine hue + mood tags (e.g., `["Teal", "Clay", "Dark", "Moody"]`)
- **0-3 moods per image** alongside hue tags
- **Order matters:** First tag = primary for title generation
- **Title pattern:** Primary hue + hexes (e.g., "Sunset Palette #ff8c42...")
- **Mood in titles:** Only as secondary phrase when it strengthens the query
- **Warm/Cool mood:** Use only when palette temperature fights the hue (NOT auto-echo like Sunset→Warm or Ocean→Cool)
- **Hue vs mood:**
  - "Cool grey" = hue (color descriptor)
  - "Cool" = mood (temperature descriptor)
  - "Dark" = mood (lightness/atmosphere)
  - "Ink" = hue (deep blue-black color)
  - "Clay", "Sand", "Cream" = hue (earth/neutral colors, NOT moods)
  - "Red" = hue (true red / high chroma), distinct from Pink (light red), Coral (orange-red), Magenta (purple-red)
  - "Navy" = hue (deep blue), "Burgundy" = hue (deep red-purple), "Rust" = hue (orange-brown), "Emerald" = hue (green), "Brown" = hue (earth tone)

### `swatches/` (auto-generated)
Palette swatch PNGs (320×48) generated by `next-curation-batch.mjs` for each batch.
Not committed to git. Each run generates swatches only for the requested images.

## Workflow

### Get Next Batch for Curation
Run the script to get the next 20 (or custom count) uncurated images:

```bash
# JSON output (default)
node scripts/next-curation-batch.mjs

# Custom count
node scripts/next-curation-batch.mjs --count=50

# Markdown format for chat (includes image previews + swatches)
node scripts/next-curation-batch.mjs --format=markdown
node scripts/next-curation-batch.mjs --count=20 --format=markdown
```

The script:
- Enumerates all JPEGs in `public/unsplash_images/`
- Sorts numerically by image ID
- Excludes already-curated images (IDs in `curation-picks.json` picks)
- Returns the first N uncurated images
- Attaches vision-based suggestions when available (legacy scene categories)
- Includes extracted palette hexes (4 colors per image)
- Generates swatch PNGs in `data/swatches/` (320×48, horizontal color strip)
- Uses stable `raw.githubusercontent.com` URLs on main branch

### Lock Curation Decisions
After QC in chat, manually edit `curation-picks.json` to add picks:

```json
{
  "picks": {
    "42": {
      "tags": ["Sunset", "Gold", "Warm"],
      "tier": "public",
      "lockedAt": "2026-09-28T10:30:00Z",
      "lockedBy": "vaisakh"
    },
    "43": {
      "tags": ["Forest", "Dark", "Moody"],
      "tier": "tag",
      "lockedAt": "2026-09-28T10:31:00Z",
      "lockedBy": "vaisakh"
    }
  }
}
```

**Tag Guidelines:**
- Use atomic tags only (e.g., `["Pink", "Bold"]` NOT `["Pink & bold"]`)
- Mix hue + mood tags (0-3 moods per image)
- Order matters: first tag = primary for titles
- Choose appropriate tier: `public` (main indexed pages), `public-alt` (next launch), `tag` (filter only)
- Warm/Cool mood: only when palette temperature contrasts the hue

Update the `updatedAt` timestamp at the top level when saving changes.

### Future: Automation Script
A future `scripts/lock-picks.mjs` could streamline locking:
```bash
node scripts/lock-picks.mjs --id=42 --tags="Sunset,Gold" --tier=public --by=vaisakh
```

## Data Flow

1. **eevee** runs `next-curation-batch.mjs` → gets next 20 images with suggestions + swatches
2. **Vaisakh** reviews in chat → QCs atomic tags and tier for each image
3. **Manual edit** of `curation-picks.json` → locks decisions
4. **Repeat** → Next run of script skips locked images

## Progress Tracking

Check remaining uncurated images:
```bash
# Total images
ls public/unsplash_images/*.jpg | wc -l

# Already curated (count picks in JSON)
cat data/curation-picks.json | jq '.picks | length'

# Or run the script with large count to see what's left
node scripts/next-curation-batch.mjs --count=9999 | grep -c '"id"'
```

## SEO Model

- **Tags** (many per image): Atomic color/mood descriptors for publishing filters
- **Title/H1**: Uses primary tag (first in array) + hex colors on `/palette/{id}/`
- **Tiers**: 
  - `public` = shortlist for indexed pages (SEO priority)
  - `public-alt` = next candidates for expansion
  - `tag` = tags only (no dedicated page, filter/search only)
